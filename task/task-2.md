# Task: Humanize Website Copy and Remove AI-Sounding Language

Review the entire existing website and improve all user-facing text so it feels natural, personal, and genuinely written by a human.

## Context

This is a personal website for a couple to discover places, save destinations, view location photos, and plan dates or activities together.

The website should feel like a small, personal space made for two people — not a commercial travel platform, AI-generated landing page, or generic dating app.

## 1. Desired Writing Style

Use a tone that is:
- Natural and conversational.
- Warm, personal, and slightly playful.
- Simple and easy to understand.
- Sweet without being cheesy.
- Casual without sounding childish.
- Genuine rather than overly polished.

Write as if a real person created the website for their partner.

## 2. Remove Common AI Writing Patterns

Identify and rewrite wording that:
- Sounds like generic marketing copy.
- Uses unnecessarily elaborate or emotional descriptions.
- Repeats the same ideas across multiple sections.
- Uses exaggerated adjectives such as "magical," "perfect," "unforgettable," or "extraordinary."
- Overuses words like "discover," "explore," "journey," "adventure," and "cherish."
- Uses formal or robotic confirmation messages.
- Includes generic descriptions that could belong to any website.
- Uses long sentences where a short, direct sentence would work better.

Do not simply replace one set of AI clichés with another. Make the wording specific to its context.

## 3. Writing Examples

Use these examples as guidance, not as fixed text to copy everywhere.

| Instead of | Prefer |
|---|---|
| Discover amazing destinations | Where should we go? |
| Create unforgettable memories together | Let's do something fun |
| Explore our curated destinations | Places we could visit |
| Your next romantic adventure awaits | Any plans for this weekend? |
| Save your favorite destination | Save for later |
| Your itinerary has been created successfully | Our plan is ready |
| No destinations found | Hmm, nothing here yet |
| Begin your journey together | Let's pick a place |
| View destination details | See the place |
| Plan your perfect date | Let's plan a date |

Keep wording appropriate to the actual context. Not every screen needs to be romantic, playful, or written as a question.

## 4. Review the Entire Website

Inspect all user-facing copy, including:

- Homepage headings and descriptions.
- Navigation menus and page titles.
- Destination cards and location descriptions.
- Photo galleries and location detail popups.
- Map markers, tooltips, and map controls.
- Search fields, filters, and category labels.
- Saved destinations and favorites.
- Date planning forms and activity selections.
- Date itineraries and schedules.
- Buttons, dialogs, and confirmation messages.
- Empty states, loading messages, and error states.
- Mobile navigation and responsive layouts.
- Notifications and other interactive elements.

Pay particular attention to text that sounds repetitive, overly descriptive, or unnecessarily formal.

## 5. Preserve the Existing Project

This task is primarily a copywriting improvement, not a redesign.

- Do not change the visual design, layout, color palette, typography, or spacing.
- Do not change existing functionality, routes, APIs, or database logic.
- Do not introduce new dependencies.
- Do not remove useful information simply to make text shorter.
- Preserve accessibility labels and clear instructions for interactive controls.
- Keep existing language conventions consistent.
- Avoid unnecessary refactoring or unrelated changes.

## 6. Review Before Applying Changes

First, inspect the existing website and identify the wording that needs improvement.

Then make the changes directly in the relevant files. Preserve good existing copy rather than rewriting everything indiscriminately.

After implementation, review the website as a whole and check that the tone is consistent across all pages.

Ask yourself:
- Would a real person actually say this?
- Does this sound like a product advertisement?
- Is this sentence longer than necessary?
- Does the wording feel natural for a personal website made for a couple?
- Does the text fit the action the user is performing?
- Is the wording still clear and useful?

## 7. Completion Report

When finished, provide:
1. A summary of the improvements.
2. The files modified.
3. A few examples of before-and-after wording.
4. Any remaining AI-sounding text that needs further review.
5. Confirmation of which existing checks or tests were run.

Make the smallest set of changes necessary to make the website feel more personal, natural, and human-written.
